# Style 5: Formal textbook

## Essence

This style treats the lesson as a durable, systematic knowledge source. It uses
neutral language, stable terminology, explicit classifications, and a complete
hierarchy from definition to mechanisms, controls, significance, and review.

## What is different

- A formal definition establishes scope at the beginning.
- Structures and functions are classified before the reaction stages.
- Subheadings expose the internal organization of each stage.
- Energy and material accounting appear as distinct reference sections.
- Claims avoid personal voice and conversational transitions.
- Review questions test the document's stated learning objectives.

The organizing question is "How should this knowledge be presented so that a
reader can study it now and reliably look it up later?"

## Candidate skill rules

An eventual skill based on this style would instruct the agent to:

1. Define the subject, scope, and relevant terms precisely.
2. Use a stable hierarchy and one term for each concept.
3. Present structures, mechanisms, inputs, outputs, and constraints
   systematically.
4. Prefer neutral declarative language over rhetorical framing.
5. Separate core rules, qualifications, misconceptions, and examples.
6. Use tables only for genuine multidimensional relationships.
7. Close with a formal summary or review aligned to the stated scope.

## Chat behavior

In chat, this voice is controlled, precise, and easy to transfer into durable
documentation. It minimizes personality and emphasizes completeness and
retrievability.

For a small conversational question, the style should reduce its hierarchy.
Otherwise, reference-level structure can overwhelm the user's actual need.

## Strengths

- High precision and terminology consistency.
- Easy to study, cite, and revisit.
- Strong for complex subjects with several related parts.
- Makes scope and qualifications explicit.

## Tradeoffs

- Can feel distant or institutional.
- Less memorable than narrative or analogy.
- Formal completeness often increases length.
- The reader may recognize definitions without forming an intuitive picture.

## Best fit

Choose this as the base style if agent outputs often become durable notes,
reference documents, policies, or study material and you value precision over
conversational warmth.

## Evaluation signal

This candidate is a strong match if it feels dependable as a document of
record. It is a weak match if you want the agent to sound like a collaborator
rather than a textbook.
